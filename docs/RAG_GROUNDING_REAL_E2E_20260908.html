2. 실제 검색 E2E 결과

모든 요청은 X-Grounding-Trace: true로 호출해 검색 결과와 trace.snapshots를 함께 검증했다.

시나리오결과Snapshot상태판정
강릉 관광지 기본 검색5개5개모두 OKPASS
음식점 + 반려동물·휠체어 조건5개5개모두 INSUFFICIENT_EVIDENCEPASS
숙소 + 반려동물 조건5개5개모두 INSUFFICIENT_EVIDENCEPASS

확인한 Grounding 계약

  • 검색 결과 장소 ID와 snapshot의 place_id가 1:1로 일치했다.
  • 각 snapshot에 source, content_version, facts, evidence, missing_fields가 포함됐다.
  • 근거가 없는 정책값은 추정하지 않고 missing_fields와 INSUFFICIENT_EVIDENCE로 처리했다.
  • 영업시간 근거는 opens_at, closes_at evidence로 확인됐다.

4. 자동 테스트

$env:PYTHONPATH = "performance/rag_grounding"
python -m unittest discover -s performance/rag_grounding -p "test_*.py" -v

6개 테스트 통과

  • 60개 grounding adversarial 케이스 검증
  • 숫자·문서 ID·출처 누락·정책 반전·문서 간 혼합 탐지
  • Guarded configuration의 계약 위반율 0%
60개 케이스 평가는 합성 데이터 기반 계약 검증이며 실제 운영 LLM의 환각률을 의미하지 않는다.
