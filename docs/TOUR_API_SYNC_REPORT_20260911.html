RAG 검색 및 Elasticsearch 재색인 확인

임베딩 기반 재색인을 위해 embedding 서비스를 healthy 상태로 기동하고, Spring 검색 엔진을 실제 구현된 elasticsearch로 설정했다. 최신 데이터 기준 원본 3,096건이 모두 색인됐고 실패 0건으로 alias 전환까지 완료됐다.

임베딩multilingual-e5-small, 384차원, embeddingStatus=ready

검색 재확인강릉 맛집 5건 반환, evidence 5건

재색인 보호 키는 로컬 환경에만 설정했으며 이 문서에는 기록하지 않았다.

  • 동기화 API는 관리자 인증 후 호출
  • 운영 환경에서는 대량 상세 동기화의 rate limit과 빈 응답 재처리 필요
